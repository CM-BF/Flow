# SVC01 个人常驻真实预览

用户要求产品界面可随时查看并进行真实持续对话。本任务提供独立个人中心、runner 和产品 Web 的本地启动/状态/停止入口；临时两轮验收仍独立，不能把其清理后的服务当常驻交付。

## 范围与验收

复用现有中心与 runner 入口和产品 Web，不重造调度器、不增加依赖。专属持久 PostgreSQL 数据库、工作目录与权限0600的配置；首次创建不得接管已有库，重启核对持有标记和任务记录，不能默默消费其他库待执行任务。启动0模型、无预热/示例；只有用户主动提交turn触发执行。固定配置/每query限额不是项目总硬预算，配置存在也不是runner/provider在线证明。

启动器只停止自己记录且核对身份的进程；不扫描端口杀进程，不关闭用户4320/49922。日志脱敏，不复制用户登录凭据。产品界面新的实际URL交Goal Owner单独打开；原fixture保留。实际模型/权限、unsupported与最后成功事实必须如实展示，Web由唯一外部owner接入。
