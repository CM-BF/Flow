/help — List available commands.
/conversations [cursor] — List one page of saved conversations.
/open <id> — Observe a saved conversation.
/profiles [cursor] — List configured execution profiles; availability remains unprobed.
/new [--profile <id>] [title] — Create a conversation; does not itself start a model.
/send <text> — Submit a follow-up; configured execution may call a model.
/recover — Explicitly replay one unresolved original request, or reload current history.
/disconnect — Stop observing. Center tasks keep running.
/quit — Exit without cancelling center work.
