createSteeringControl(identity,port) exposes immutable snapshots/subscription, updateGate, refresh/loadMore, submit, retry, clearResolved and dispose. Identity is connectionScope/taskId. Three ports are bound admission/readState/accept, supplied by host private FlowClient methods. Every physical call requires current host authority; caller must invalidate/dispose on connection switch or revoke. No token/client/SDK surface is passed to UI. Actual exported types are the definitive consumer interface.

TaskSummary has no attempt. A validated admission supplies attempt/owner/revision; no harness inference or attemptAvailable authorization. UI opening explicitly reads; hidden/offline/unauthorized makes no new reads. No polling. A refresh rereads every loaded page (max64 commands per attempt) so receiptRevision changes are visible even when control revision is unchanged. Older attempts/receipts have a finite local bound. Unknown receipts are never evicted; capacity blocks a new handoff, resolved entries can be explicitly cleared.

Submission uses strict public schema, UTF8≤16384, no blank/NUL/unpaired-surrogate. A synchronous preparing gate covers asynchronous digest; post-digest gate/generation check precedes allocating a key. Frozen original key/body survive retry in the page; a new draft is independent. Runtime validates ACK shape, task/attempt/owner, command revision=expected+1, UTF8bytes/digest, command/session/UUID. Admission has no nativeSessionId: the first valid server ACK establishes opaque native identity; subsequent metadata/replays must agree. Saved first ACK only confirms receipt and never replaces a newer receiptRevision state.

Readiness is advisory. POST may fail CAS; refresh but never auto-resubmit with a new revision/key. Owner/profile checks precede idempotency replay, so a prior unknown remains unknown even when retry is4xx after attempt/permission changes. Retrying an unknown bypasses only new-send admission, never host authorization or connection identity. Unknown malformed2xx/timeout/abort/5xx does not prove rejection. accepted/received/observed-consumed are distinct center/runner facts, not model compliance. Hidden does not cancel center work.

This independent UI uses existing primitives and its own draft, not an assistant-ui queue adapter. Actual P01/App/Thread wiring is separate. Cross-reload original-key recovery is not promised: this module is page-memory only and must warn before disposal; stable credential-free storage namespace remains follow-up.
