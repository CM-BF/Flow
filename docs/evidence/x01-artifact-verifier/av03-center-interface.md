State owner: the existing runner lock, allocation transaction and compact `flow.commands` receipt. The domain client uses FlowClient's one request/credential/error/abort path; no retry or fallback. The request is detached before awaiting the lock/transport. One key includes all v4 verifier and optional tool qualification. v2/v3/v4 keys conflict across protocols, while idle polls remain unrecorded.

`036-plugin-verification-bindings.sql` derives positive immutable kind from exact installed receipt / registration / version / store / material / tree / artifact / manifest. It creates a separate immutable binding-kind table, avoiding update of034's immutable rows. Valid old tool writers are enriched by the same insert trigger. Missing/mismatched historical tool evidence aborts the migration; no absent-reference default. Verifier references have a deferred mandatory reverse check, composite kind FK, exact artifact task/attempt/id/version FK, finite rule and project identity. No public producer of new verifier tasks is exposed in this slice.

The shared claim SQL filters positive tool/verifier kind, runner, current store/API, algorithm and current grant before its original ORDER/LIMIT. Legacy v1/v2 pass no host; v3 passes only tool host; v4 does not imply tool capability. Allocation/replay then holds the existing runner→task→registration order, rechecks registration scope/current grant and exact published host, reads the frozen verifier reference, and checks source plus verifier-task authoritative project relations. Direct project bindings are share-locked; immutable conversation relation must agree, including workspace. Missing/null/conflicting authority is refused, never inferred from caller data. Source body is selected by exact artifact tuple, capped8192UTF8, hashed against version and compared with the parsed frozen task input/rule. One physical source relation remains immutable; future project unbinding can make a claim unavailable, not rewrite its pin.

Assigned v4 responses carry exactly one ordinary/tool/verifier assignment and the original compact identity. The strict codec rejects mismatched attempt/runner/qualification, accidental tool capability, algorithm/reference or prompt-source mismatch, and the wrong claim/status state. Response canonical envelope is131072bytes, read by existing bounded transport; unknown ACK/cancellation does not resend. Current live lease is returned without renewal; existing capacity/session/owner fences remain.
