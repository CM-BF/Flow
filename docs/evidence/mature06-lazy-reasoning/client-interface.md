# Public selected-stream transport slice

Fixed adopted client baseline: main `2a7e004b5ab7ceb2e44903af92aaf251cdda0e8a`. One FlowClient/request retains Bearer/cookie, CSRF, JSON reads, cancellation, FlowApiError and no retry. Native activity body and native-conversation interfaces are preserved verbatim.

`assistantStreamProtocol: patch-select-v1` explicitly selects task stream reads. `assistantStreamSelectedMetadata` returns a page with its checked protocol/task ACK; every page rechecks it. `assistantStreamSelectedPatches` takes copied finite selection + attempt/after/limit and validates returned selection, task/attempt, ordered global sequence and exact next cursor. Existing `assistantStreamPatches` defaults to text only under this explicit mode. `assistantStreamBlock` reads a single complete block with task/stream identity checks. Stream responses use the existing JSON transport; this slice does not add a network-byte hard cap. The trusted server bounds pages/blocks and the projection validates cumulative resident bytes after decoding. Native material transport retains its distinct 384KiB bound unchanged.

The client is stateless transport, not a second projection. The existing ConversationStreamProjection remains the metadata-first authority: it must accept the metadata ACK before invoking body ports; it owns full source/content/hash verification, generations, complete metadata partition, per-selection cursors and cumulative resident limits. Full block GET has the existing block envelope (no invented ACK); the projection compares its attempt/source/revision and verified digest against acknowledged metadata. A raw direct block call alone is not evidence of server protocol support. These methods bind to the existing StreamPort; no Web host consumer is changed in this slice.

Conversation snapshot reads keep patch-v2 when the task-stream mode is selected, since selection is a task-read capability, not a changed conversation decoder. Existing unset/v1/v2 branch semantics are unchanged. No mutation payload, retry or durable state is added.

Direct checks cover transport/auth/encoding, mutable option detachment, per-page ACK mismatch, wrong attempt/selection/hidden reasoning, cursor gaps and empty cursor preservation, Unicode codec rejection, pre-abort/error and legacy behavior. Full public HTTP/PG with this new transport and Web/TUI mounting remain future acceptance; prior PG2 is core/server evidence only.
